## What I'm building

**[continuity-engine](https://github.com/andrew-lord-dev/continuity-engine)**
A file-based memory architecture for persistent AI agents. Plain JSON, no database.
- A two-tier store: a small working memory loaded each session, and a deep archive searched on demand
- A consolidation cycle modeled on sleep, which moves older entries to the archive
- A "lived time" day counter that advances per cycle, not per calendar day
- Extracted from a live system I've run daily since early 2026

Public now: the consolidation engine and a screen-vision server.
In progress: the memory server, an inner-dialogue layer, an ambient monitor, and tests.
